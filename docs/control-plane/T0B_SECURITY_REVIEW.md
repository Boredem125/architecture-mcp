**Claim 21, answered.** Does default-false leave a downgrade? Yes, one, and it is today's limit, not a new one. A device that has not yet applied a switch-on bundle stays on the server-reported operator, and a compromised server can hold it there by withholding that bundle or by stopping a fresh enrolment at an older row. Once a device has applied it, turning it off needs what every loosening needs. **What signs it:** two `agg/policy-change/v1` approvals from distinct CLI users over the bundle hash, which covers the field, checked by the connector against its own last valid bundle. The bundle-signer signature gives no authority. Hand edits do not reach it, because the enforced value comes from the signed bundle (`verified_state.py:72`; `policy_versions.py:586`). Default false is acceptable because the frozen gate needs it and it opens nothing new.

**Guarded properties.** Local enforcement stays authoritative and fails closed, apart from the small gap in F-4. Models: nothing here touches them. Signed and chained: the ADRs left out publish, restore and binding, now added (F-10). Dual control: F-2 and F-3. Hand edits: hold.

- **F-4 Low.** A managed device with no known operator must refuse remote approvals. Owner: T9b, with F3 or on its own if F3 moves to M4.
- **F-5 Pilot exposure.** The ACME path has a login page on the internet. Material must not imply an internal-only deployment (ADR 0013 open question 1).
- **F-6 Approver's diff.** A diff against a base the server supplies is the server's word, even when computed on the laptop. Fixed in A9 item 7 (threat 40).
- **F-7 Design dependency for M4.** Custody exists for prod credentials, but in broker mode nothing can approve on prod until a prod remote-approval path exists. Recorded in ADR 0012 item 4.
- **F-8 Spike validity.** Microsoft does not treat UAC as a security boundary ([criteria](https://www.microsoft.com/en-us/msrc/windows-security-servicing-criteria)). Probes from an Administrators account would prove less than they appear to, so Sp1 runs as a standard user, and the boundary claim is limited to developer accounts outside Administrators.

Put it in an auto-loaded `compose.override.yml`, not in the base file. `pilot.sh` passes `-f` explicitly, which skips the override, so the pilot cannot inherit it by accident. T5's test asserts the merged result.
- **F-10 Chained records.** Publish, proposal, approval and binding now write `admin_audit` rows. `restore` writes one after the data returns, because a rewound chain cannot show its own rewind.
- **F-11 Restore is an incident.** It undoes revocations and role changes made after the backup and may revive old codes and sessions. Stated in ADR 0013's limit.
